Device to connect a computer/device to network

It can be configured to offload tasks and perform a variety of things:

- High resolution timestamp for accurate measurement of performance etc.
- Hashkey lookup to route to the correct server -> load balancing (Receive side scaling)
- Higher order synchronised timestamping using PTP (Precision time protocol)
